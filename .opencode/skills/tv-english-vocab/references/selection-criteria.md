# B2–C1 selection criteria

Read this before picking words. The goal is words an intermediate learner does
**not** already own but can actually use, not a dictionary dump.

## Include

| Category | Examples |
| --- | --- |
| B2 vocabulary in a non-obvious sense | `legitimate` as "合法的/正当的" when the show uses it morally, not technically |
| C1 vocabulary | `acquiesce`, `obfuscate`, `provisional`, `untenable` |
| Multi-word expressions (chunks) | `wash your hands of it`, `not my cup of tea`, `burn the candle at both ends` |
| Verb + particle / phrasal verbs | `talk down to someone`, `sit on something`, `cash in on` |
| Idioms the show actually uses | `in over your head`, `keep someone at arm's length` |
| Collocations with a fixed partner | `heavy rain` (not "big rain"), `draw a conclusion`, `meet a deadline` |
| Register / slang / informal | `dude`, `scumbag`, `nut` (= crazy person), `swag` |
| Register contrast pairs | where the script shows `informal` vs `formal` doing the same job |
| Domain vocabulary | `indictment`, `jurisdiction`, `syringe`, `yield curve` |
| Workplace collaboration | `run over` (= overrun), `loop someone in`, `take this offline`, `push` (= promote), `circle back` |

## Workplace register

When the show is set in a workplace, this carries the most weight. Prioritise
it over clever wordplay.

| Type | Examples |
| --- | --- |
| Status / timing shorthand | `run over`, `push the date`, `circle back`, `touch base`, `bandwidth` |
| Meeting language | `loop someone in`, `take this offline`, `let's table that`, `park it`, `for the record` |
| Reporting & escalating | `flag it`, `heads-up`, `walk someone through`, `bring someone up to speed`, `in the weeds` |
| Evaluation | `curveball`, `low-hanging fruit`, `a hard sell`, `net-net` |
| Negotiating | `push back`, `meet halfway`, `non-starter`, `where does that leave us` |
| Vague corporate register | `moving the needle`, `unpack` (= analyse), `ideate`, `deliverables` |
| Interview / hiring | `a strong hire`, `culture fit`, `next steps`, `sell them on it` |
| Where native speakers fail to reach | `I'd sleep on it`, `that's a fair ask`, `for what it's worth`, `I'd push back on that` |

## Exclude

- Function words and grammar glue: `actually`, `kind of`, `you know`, `I mean`
- Anything a B1 learner already covers unless the show uses it in an
  unfamiliar register: skip bare `hospital`, `angry`, `run away`
- Proper nouns of characters and places (mention them in `note` if the context
  matters, never as entries)
- Slurs and profanity used purely as shock value, unless the word itself is
  the interesting unit and you note that it is offensive
- Single-use stage directions, unless they contain a learnable chunk
- **One-off joke coinages the episode invents for a gag.** `chemical
  disincorporation`, `coin flip is sacred`, `my arches happen to be extremely
  archy` — nobody says these. Keep a pun only when the underlying expression is
  real (`banana cabana` qualifies, `disincorporation` does not)
- **Full clauses dressed as chunks.** `we should be way past this`, `let's get
  outta here` are plot dialogue, not storeable expressions. The item must work
  outside this scene

## Chunk share

Short phrases carry most of spoken English, so a phrase-heavy list is correct —
but do not let them crowd out the single-word base.

| Level | Phrase share of entries |
| --- | --- |
| B2 | 40–50% |
| C1 | 60–70% |

When a meaning can only be built from words — academic, technical, abstract
concepts — **take the word, not a strained phrase**. A B2 learner needs
`inoperable`, `adulterants`, `erstwhile` more than a fourth idiom.

## Level assignment

- **B2** — a learner can grasp the meaning but would hesitate to produce it.
  Concrete and high-frequency: `deliberate` (adj.), `brutal`, `hold up` (= delay).
- **C1** — a learner needs it for fluent, nuanced, academic or professional
  register: `untenable`, `aforementioned`, `come clean`, `not for all the world`.

When genuinely torn, choose the **lower** level. Inflating to C1 makes the
export useless. Typical yield for a 40-minute episode: **20–35 entries**,
roughly 60/40 B2 to C1.

## Field rules

- `word` — the headword as the learner would store it, lowercase, inflected
  forms preserved when the sense is form-bound (`smirk` not `to smirk`).
- `phonetic` — IPA in `/ /`. British or American, pick one and stay
  consistent; note the other in `note` only if it differs meaningfully
  (`schedule` `/ˈskedʒuːl/` AmE vs `/ˈʃedjuːl/` BrE).
- `pos` — dictionary style: `n.`, `v.`, `adj.`, `adv.`, `phr. v.`, `phr. n.`
- `meaning_en` — one clause, no example sentence; define the sense used here.
- `meaning_cn` — natural Chinese; include the register or connotation
  (`钻空子牟利` not just `操纵`).
- `quote` — copy from the transcript. If the transcript line looks like a
  subtitle error, quote it anyway and flag it in `note`.
- `example` — **not** the quote again. A fresh sentence showing typical use,
  ideally a different context from the show.
- `note` — the thing that makes this item worth learning: a common
  miscollocation, a register warning, a near-synonym contrast, a
  pronunciation trap.
